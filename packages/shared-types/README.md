# @pravah/shared-types

Shared TypeScript models, interfaces, enums, and API contracts for PRAVAH frontend and microservices.

## 📦 Usage

```bash
npm install @pravah/shared-types
```

```typescript
import { User, Organisation, SocialAccount, Post, Plan } from "@pravah/shared-types";
```

## 🔨 Build
```bash
npm run build
```
